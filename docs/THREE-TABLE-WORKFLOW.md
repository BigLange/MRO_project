# 三表流程（旧版基线）

2026-11-10用户确认：表1浮动比例支持数字110、百分比、原文字以及公式已保存结果；Excel/WPS重新计算保存后需重导表1。辅助重量约80%位于区间两端各25%内、其余约20%在中间。详见 `CUSTOMER-CHANGES.md`，其余流程仍按下列旧基线。

用户要求按旧版程序及原始模板恢复，新增功能后续逐项提出。已撤回的额外改动见 `LEGACY-BASELINE.md`。

1. 主程序导入表1标准表。请重新导入一次，以使用 `standard-catalog.v4.json`；重复条码按旧版取首次记录，当前为104个产品。
2. 辅助程序“导入Excel”：表2首工作表A列为条码、B列为数量。未知条码跳过，空白或无效数量在界面补填；也可新增条目手工录入。
3. 辅助程序填写抽样基数，可手填最大值；最大值为空时使用规格×浮动比例。点击“预览样品数”及“生成标准表”，只输出一份称重表。
4. 称重表保留原8列：序号、日期、时间、皮重、重量、毛重、单位、扫描。使用原W250905模板，不新增来源、批号等栏目或隐藏数据。
5. 主程序分析称重表后，填写抽样基数，或用“一键生成标准抽样基数”按记录数量反查旧规则。选择报告日期，导出报告。
6. 每个商品独立输出 `前缀_商品名_批次检测报告.xlsx`；另输出 `前缀_批次检测报告结果.xlsx`。汇总每页15个商品。无合并明细、追溯页、说明页或新增标记。

报告直接使用原始 `ReferenceReports/检测报告1.xlsx` 和 `检测报告2.xlsx` 的表单样式。感官默认“正常”，结论“符合规定／不合格”，日期和编号沿用旧版默认方式，不再加“规则生成”“未录入”“待复核”等文字。

主程序按旧版计划补足或裁减记录，判断使用旧T1/T2计数口径，平均值按旧版保留1位。21–31的批量仍按旧规则生成32个样品。详细依据、撤回项和已知边界见旧版基线文档。

原模板与标准表不覆盖；导出同名文件按原程序替换，技术上先暂存并支持失败回滚。17组Core检查及48组旧DLL对比通过，实际客户样表、所有DPI、Excel/WPS打印和安装/卸载仍需验收。
